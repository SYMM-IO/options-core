Shared documentation reader

The CSS, reader JavaScript, portal JavaScript, fonts, logo, and Mermaid bundle are copied from the local perps-core/docs site. Options Core uses the same reader layout and controls.

The Options Core copy loads fonts and Mermaid from beside the reader assets. It uses the options-docs-theme storage key and loads the chapter manifest generated by scripts/build-docs.mjs. Edit the HTML files under docs/pages/, then run npm run docs:build.
