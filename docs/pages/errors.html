Custom Errors Reference

Custom errors, trigger conditions, and call sites.

Every revert path in Options Core uses a typed custom error. Errors are grouped by domain in contracts/errors/*.sol; helper contracts (MultiAccount, InstantLayer, SymmioPartyA, SymmioPartyB, TradeNFT, MuonOracle) define their own inline errors. This page lists every error, its arguments, the trigger condition, and one to three representative callsites with file:line.

Inherited OpenZeppelin 5 Errors

The helper contracts inherit OpenZeppelin 5, which reverts with custom errors instead of the revert strings OpenZeppelin 4 used. Off-chain code that matches OpenZeppelin 4 revert strings must switch to ABI-decoding these custom errors. They are declared by the OpenZeppelin base contracts, not in this repo, so they do not appear in contracts/errors/.

Error Raised by Replaces (OpenZeppelin 4 string)
AccessControlUnauthorizedAccount(account, role) MultiAccount, SymmioPartyA, SymmioPartyB, InstantLayer, MuonOracle AccessControl: account ... is missing role ...
EnforcedPause() MultiAccount, SymmioPartyB (whenNotPaused functions, pause() twice) Pausable: paused
ExpectedPause() MultiAccount, SymmioPartyB (unpause() while not paused) Pausable: not paused
InvalidInitialization() MultiAccount, SymmioPartyB (initialize called a second time) Initializable: contract is already initialized
ReentrancyGuardReentrantCall() SymmioPartyB, InstantLayer (nonReentrant functions) ReentrancyGuard: reentrant call

Common Triage Patterns

The errors below cover the bulk of revert tickets seen in normal trading flows. Each row is "what to check first."

Error Quick fix
BalanceLimitExceeded Means deposit + balance would exceed balanceLimitPerUser[collateral]. Check the user's whitelist tier or have an admin raise the limit; only Party A users are bound by it.
InsufficientBalance The relevant pocket (isolated free, locked, or reserve) is short. Confirm which by the available field and re-check whether funds are still locked in an open intent.
CollateralNotWhitelisted Collateral token must be whitelisted via ControlFacet.addCollateral before any deposit.
NotSolvent A liquidation id already exists for the (party, counterParty, collateral) triple. Wait for liquidation cleanup or pick a different counterparty.
IntentExpired / IntentNotExpired Off-chain clock drift or stale intent. Resubmit with a fresh deadline, or wait until the deadline really passes for the force/expire path.
NotWhitelistedPartyB Party A's partyBsWhiteList excludes the locking solver. Either Party A re-issues the intent with the right whitelist or another Party B picks it up.
OracleMismatch Party B's partyBConfigs[partyB].oracleId does not match the symbol's oracle. Update the Party B config to support that oracle.
SymbolTypeNotSupported Admin must enable the symbol type for that Party B via ControlFacet.setPartyBSupportedSymbolTypes.
InvalidOpenPrice / InvalidClosePrice Fill price violated Party A's threshold; retry with a price that respects the side (better or equal).
InvalidFillAmount Fill quantity exceeds the remaining intent quantity; reduce it or refresh the off-chain view of availableAmount.
CooldownNotOver Generic cooldown gate. The cooldown string identifies the bucket: "withdraw", "forceCancel*", "forceClose*", "unbinding", instant-actions deactivation. Wait for requiredTime to pass.
GlobalPaused / *ActionsPaused The corresponding pause flag is set by ControlFacet; wait for the operator to unpause or use a different entry path.
